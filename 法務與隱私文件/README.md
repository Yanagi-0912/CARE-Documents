# CARE 法務與隱私文件

> 文件狀態：內部草案，尚未經法律專業人員審閱，不得直接視為正式法律意見或原樣發布。

本目錄提供 CARE 在蒐集及使用個人資料時所需的四份基礎文件：

1. [個人資料蒐集告知事項](./個人資料蒐集告知事項.md)
2. [隱私權政策](./隱私權政策.md)
3. [健康敏感資料同意書](./健康敏感資料同意書.md)
4. [服務條款](./服務條款.md)

## 文件用途

| 文件 | 主要用途 | 建議出現時點 |
|---|---|---|
| 個人資料蒐集告知事項 | 履行蒐集個資前的法定告知 | 首次註冊／啟用 CARE 前 |
| 隱私權政策 | 完整說明資料生命週期、分享、安全及權利 | 官網、LINE／LIFF 設定頁持續可查閱 |
| 健康敏感資料同意書 | 取得病歷、醫療、健康檢查或可能涉及性生活資料的可證明同意 | 首次使用相關功能前；用途重大變更時重新取得 |
| 服務條款 | 建立服務契約、功能界線及雙方權利義務 | 首次啟用服務前，並提供可下載或保存版本 |

## 不可合併處理的授權

下列事項應採分層、即時且可撤回的授權，不應只依賴註冊時的一個總括勾選框：

- 裝置定位及防走失期間的位置分享。
- 將健康資料分享給特定家庭成員。
- 上傳藥袋、圖片、音訊、影片或文件供 OCR／AI 處理。
- 讀取裝置動作感測器及產生步數。
- 經期資料的蒐集與使用。
- 非服務必要的通知、研究、產品改善或行銷用途。

## 上線前必填與決策

- [ ] 服務提供者法定名稱、統一編號、地址及負責人。
- [ ] 個資與客服聯絡窗口。
- [ ] 各類資料的確切保存期限及備份清除週期。
- [ ] Google Gemini、LINE、雲端、OCR、通知及監控服務的實際供應商、處理地區與契約保障。
- [ ] 是否將使用者內容用於模型訓練、人工檢視、研究或產品改善；預設應為不使用，除非另行明確同意。
- [ ] 藥袋原圖、OCR 全文、掃描草稿與完整風險報告的資料分類及保存期限（對應 SRD `OR-02`）。
- [ ] 帳號終止後一般資料、稽核紀錄與備份的保存及刪除規則。
- [ ] 未成年人、受監護或輔助宣告者的身分及代理權驗證流程。
- [ ] 服務條款合理審閱期間與第一審管轄法院。
- [ ] 依實際營運身分確認主管機關及是否適用特定產業的個資安全維護辦法。
- [ ] 由熟悉台灣個資、消費者保護及醫療資訊法規的法律專業人員完成上線前審閱。

## 產品與系統落地要求

- 所有同意均不得預先勾選，拒絕選填用途不得阻擋不相干的基本功能。
- 保存 `user_id`、文件種類、版本、語言、顯示時間、同意／拒絕時間、同意範圍、來源裝置及撤回時間。
- 重大用途、資料類別、接收者、跨境地區或保存期間變更時，應重新告知；依法須同意者應重新取得同意。
- 隱私設定應提供查閱、更正、停止處理／利用、刪除、撤回分享及聯絡窗口。
- 系統角色 `GUARDIAN`、`CAREGIVER` 不等於法律上的法定代理人，也不會自動產生代替本人同意的資格。
- LINE 的平台授權不取代 CARE 自己的個資告知、健康敏感資料同意或家庭分享授權。
