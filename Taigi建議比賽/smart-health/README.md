## 資格與文件

- 全國大專校院在學學生，含研究生。
- 每隊 2 至 5 人，可跨校、跨系、跨領域；指定 1 名代表人。
- 可邀請 1 至 2 名指導老師。
- 線上報名表。
- 附件一：參賽團隊報名表。
- 附件二：全體成員及指導老師簽名的參賽聲明書掃描檔。
- 附件三：15 頁以內「創業實作營運計畫書」，封面不計頁，PDF。
- 檔名：`B_學校名稱_團隊名稱.pdf`。

## 評分方式

| 項目 | B 組權重 |
| --- | ---: |
| 問題洞察／場域需求 | 20% |
| 創新性與差異化 | 20% |
| 智慧科技應用合理性 | 15% |
| 可行性／作品完成度 | 20% |
| 健康照護與社會價值 | 10% |
| 應用、市場與商業化潛力 | 15% |

決賽每隊 13 分鐘，原則上 8 分鐘簡報、5 分鐘問答；B 組須展示作品或 Demo。

## Gap Analysis

### 已有

- LINE／LIFF 可操作原型。
- 台語 STT/TTS、健康資訊 RAG、藥袋辨識、用藥提醒、健康紀錄、家庭照護與定位功能。
- 系統需求、設計文件、程式測試與台語工程基準。

### 需要修改

- 技術說明需壓縮，主文以照護需求、使用流程與產品完成度為主。
- 將工程基準清楚標為系統測試，不寫成健康成效。
- 將 `Planned` 功能移到未來規劃。

### 尚缺

- [待補：報名表、簽名聲明書、學生證明]
- [待補：目標使用者訪談與場域驗證]
- [待補：營運成本、收費假設與驗證]
- [待補：8 分鐘決賽簡報與 Demo 腳本]
- [待補：曾參賽或獲獎揭露]
