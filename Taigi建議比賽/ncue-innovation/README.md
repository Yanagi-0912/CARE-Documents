# 2026 全國大專院校產學創新實作競賽

## 投稿資訊

- 主辦單位：國立彰化師範大學工學院、彰化縣產學精進協會
- 投稿組別：D. 人工智慧及其應用（第四組）
- 投稿定位：可實際運作的 AI 軟體工程專題
- 報名期間：2026-09-01 至 2026-10-22 23:59
- 初審結果：2026-11-12
- 決賽：2026-11-19，國立彰化師範大學寶山校區工學院
- 官方資料：[競賽介紹](https://eedept.ncue.edu.tw/innovation2026/intro.html)、[報名專區](https://eedept.ncue.edu.tw/innovation2026/join.html)

## 資格與繳件

- 全國大專院校學生，含研究生；可跨校，最多三校。
- 每隊至多 5 人。
- 報名表、組隊成員說明書、作品說明書、參賽與個資同意書、作品摘要。
- 全部附件壓縮為以隊名命名的 RAR 上傳；同意書須掃描為 PDF。
- 決賽自印 A1 海報並展示模型或成品，09:00 前完成佈置。

## 評分方式

| 項目 | 初審 | 決賽 |
| --- | ---: | ---: |
| 創新性 | 35% | 35% |
| 可行性 | 50% | 50% |
| 書面完整性／海報與作品說明 | 15% | 15% |

- [待補：A1 海報完稿]
