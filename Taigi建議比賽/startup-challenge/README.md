## 資格與文件

- 全國大專院校在校生，3 至 6 人，可跨校／跨系。
- 至少 1 名指導老師，指導老師不計入團隊人數。
- 每隊限 1 件提案，須具 AI 或新興科技核心概念。
- 全體成員身分證／護照與學生證正反面影本。
- 未滿 18 歲者須附法定代理人同意書。
- 創業構想提案書：主辦單位格式，15 頁內 PDF；可含團隊資訊、創業構想、市場洞察及 AI／科技創新。
- 報名截止後不得更換隊員。

## 評分方式

| 項目 | 權重 |
| --- | ---: |
| 創意發想與問題意識 | 35% |
| 邏輯與結構清晰度 | 25% |
| AI 技術應用與實踐性 | 25% |
| 團隊合作與表現 | 15% |

複賽至少三分之二隊員參與；決賽全員到場。評分資訊另參考主辦公告所連結之競賽資料，正式送件前應再次核對最新版簡章。

## Gap Analysis

### 已有

- 可展示的 LINE／LIFF 產品原型。
- 清楚的高齡、台語與家庭照護使用情境。
- 多模態 AI、健康紀錄與用藥功能可支撐產品可行性。

### 需要修改

- 從功能清單改寫為目標客群、價值主張與使用旅程。
- 將 B2C、B2B2C、SaaS 寫成待驗證假設，不宣稱已有營收。
- 技術只保留足以證明可實作的內容。

- [待補：成本結構與價格假設]
