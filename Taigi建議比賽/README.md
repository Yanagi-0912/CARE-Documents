# CARE 競賽投稿文件

本目錄依 `CARE-Documents/參賽文件spec.md` 編寫，整理 CARE 參加四項 2026 年競賽所需的共用事實、官方規則與投稿草稿。

## 目錄

| 路徑 | 用途 |
| --- | --- |
| `common/` | 共用專案事實、功能狀態、競賽定位比較 |
| `smart-health/` | 2026 全國智慧健康照護創新創業競賽 |
| `ai-innovation/` | 智策AI：2026 資策會 AI 創新實戰大賽 |
| `startup-challenge/` | 第五屆青春靚點子學生創業挑戰賽 |
| `ncue-innovation/` | 2026 全國大專院校產學創新實作競賽 |

## 使用原則

1. 所有功能描述以 `common/feature-status.md` 為準。
2. `[待補：...]` 須由團隊確認，不得直接刪除或自行推測。
3. 正式送件前須下載主辦單位最新附件，將草稿轉填至官方 Word、PDF 或線上表單。
4. CARE 是健康資訊與照護輔助系統，不是診斷工具，文件不得宣稱取代醫師。
5. 競賽規則查核日期為 2026-10-02；主辦單位後續公告優先。
